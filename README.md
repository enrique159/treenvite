# Treenvite
## WebApp para gestionar los invitados para tu evento

Este proyecto es una plataforma para gestionar invitados de una forma gráfica a través de una modalidad de árbol.
El enfoque principal es ofrecer una facilidad para organizar y visualizar desde una perspectiva más gráfica los invitados de un evento.

El proyecto es un monorepo que cuenta con las carpetas:
`/backend` - NestJS con TypeORM y MySQL
`/frontend` - Vue 3 con Pinia, TailwindCSS, DaisyUI
